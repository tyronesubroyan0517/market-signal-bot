# Artwork file names

Use webp, jpg, png or svg. Rebuild after adding files.

## brand/
- `monogram` : circular gold monogram, transparent background
- `hero-banner` : the wide watercolour banner with the wordmark
- `about-artwork` : the "Made to Reconnect" artwork
- `category-journals`, `category-little-hearts`, `category-becoming`, `category-celebrations`
